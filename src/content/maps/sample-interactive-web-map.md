This is a **sample interactive entry**. Set `embedUrl` in the frontmatter to any
embeddable map URL — an ArcGIS Online embed, a StoryMap, a Felt map — and it
renders as an iframe at the top of the page instead of the static image. The
`image` is still used for the card preview in the gallery.

Add `externalUrl` if there's a full-screen version worth linking out to.
